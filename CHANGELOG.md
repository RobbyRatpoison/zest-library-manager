# Changelog

Notes shown in Zest's "What's new" window after an update. One `## vX.Y.Z` section per release, newest first; bullets under `###` headings such as `### New`, `### Improvements` or `### Fixes`.

## v2026.11.1
### Zest replaces PlayDate
- Rewritten from scratch in Rust as a native app, with no built-in browser.
- Copies your PlayDate library on first start.
- Backups are cross-compatible with PlayDate.

### Faster and lighter
- Starts quickly and switches pages instantly.
- Uses a fraction of the memory and almost no CPU when idle.
- Smooth scrolling through thousands of covers.
- Missing covers download first for the games on screen.
- No Python needed. Real Mac app for Intel and Apple Silicon.

### Steam
- Sign in with Steam fills in your SteamID and API key.
- The sign-in finds owned games the Web API misses.
- Real purchase dates without the Companion userscript.
- Sign-in kept in your system keyring.

### Other stores
- All fourteen stores built in: no plugins to install or update.
- Sign-in windows for most stores instead of pasting cookies.
- Purchase dates for GOG, Epic, EA, IndieGala and PlayStation read in the background.
- Install Humble, itch.io, IndieGala and GOG games from Zest.
- More Xodus Nexus sync options for Xbox.
- Windows: Uninstall Game runs the game's own uninstaller.
- Plugins can be written in any language.

### Home and Library
- Edit Home Page: a drag-and-drop map of your shelves.
- Cover Quality filter for low-res, misshapen or missing covers.
- Finds the same game listed under different editions (Deluxe, GOTY) so you can link them.
- Six new themes.

### Imports
- Playnite import adds statuses, categories as groups and missing games, with undo.

### Gamepad
- Most controllers work without setup on every system.
- Zest ignores the controller while you are in a game.
